# 噜噜新模型（2026-11-10，胳膊平举那版）的处理脚本

2026-11-11 试验用，**没有采用、没有上线**：模型修好了、也绑了骨，但动作是代码算的，动起来僵，噜噜小兵看了说不行，先停。留着备查。

顺序（都要 `pip install bpy scipy`，在脚本所在目录外面跑，用 `python3 -I`）：

1. `base3.py`：读混元的原始 GLB，焊接，存底稿。
2. `clean3.py`：删掉漂在外面的小碎片。
3. `probe3.py`：按贴图颜色给每个点取色（后面分皮肤和短裤用）。
4. `fix3.py`：抹平褶子、把上嘴唇两侧的陡坎抹缓、淡化背后缝线。最后一个参数是嘴抹多少遍，用的 300。
5. `tex3.py`：贴图上去掉短裤侧缝的黄斑、右嘴角的红点。
6. `low3.py`：减到 3.6 万面，重新展 UV，把颜色和表面细节烘到新贴图。
7. `../rig_hippo_apose.py`：算权重、把胳膊放下来当静止姿势、建骨架、加眨眼，导出 GLB。

`hl.py`、`deform.py` 是共用的函数，`view.py` 是渲染检查图用的。
修好的高模（没减面、没绑骨）在 file-storage 的 `claude/upbeat-curie-jer3rf` 分支 `lulu-v3-fixed-20261110/`。
