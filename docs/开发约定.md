# 噜噜岛开发约定

给以后接手的 Claude（新对话、Claude 小号）看的。每个新对话都会通过 CLAUDE.md 读到这份。

## 一、显示物件的位置统一写在布置表 `layout.js`

噜噜岛和噜噜之家里所有“显示物件”（挂画、相框、天气 / 日历小屏、快递盒、地图、岛上的牌子和灯……）摆在哪，**只写在 `layout.js`**，不要在别的文件里写死坐标或墙的名字。以后搬家、换位置、改户型，只改这一个文件。

- **房子里**（`HOUSE`）：用房子自己的坐标，写 `pos`（中心位置，米）、`facing`（正面朝哪边）、大小。挂在哪面墙、属于哪个房间，程序按位置自动算（`house.addItem(obj, { auto: true })`），墙被剖开削矮时一起藏起来。
- **岛上**（`ISLAND`）：挂在房子上的写相对房子的坐标（`onHouse: true`），房子在岛上挪位置时跟着走。
- **新加显示物件**：做成正面朝 +z、原点在中心的一个 Group，在 `layout.js` 里加一行位置，用 `placeInHouse(house, obj, LAYOUT.xxx, "点击id")` 放进房子（岛上用 island.js 里的 `islandPlace`）。
- **跟着家具走的**：电视画面、玄关留言板（软木板）贴在模型里的家具上，挪家具在 `tools/build_house.py` 里改，它们自动跟着。
- **改了户型**（`tools/build_house.py`）以后：检查布置表里房子里的位置还在不在墙上、在不在原来的房间里。

## 二、私密内容不能明文放进仓库

仓库是公开的。照片、快递、日程这类私密内容，用**大门锁密码**加密后再放（`lock.js`）：
- 照片：`photo-lock.html` 生成加密文件，放 `assets/house/photos/`，挂在哪写在 `layout.js` 的 `PHOTO_SLOTS`。
- 快递、日历：Muse 在对应页面加密后发帖。
